Это тестовое задание для демонстраии навыков работы с Next js

## Запуск приложения

Что бы запустить приложение, склонируйте репозиторий и выполните следующие команды:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Откройте [http://localhost:3000](http://localhost:3000) что бы увидеть результат.
